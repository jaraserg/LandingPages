# Tic Tac Toe Game

A console-based Tic Tac Toe game with multiple game modes and an unbeatable AI opponent.

## Features

- **Multiple Game Modes:**
  1. Human vs Human
  2. Human vs Computer (Easy - random moves)
  3. Human vs Computer (Unbeatable - uses minimax algorithm)
  4. Computer vs Computer

- **Intelligent AI:** The unbeatable mode uses the minimax algorithm to play perfectly

## How to Play

1. Run the game: `python tic_tac_toe.py`
2. Choose a game mode (1-4)
3. Make moves by entering numbers 0-8:
   ```
   | 0 | 1 | 2 |
   | 3 | 4 | 5 |
   | 6 | 7 | 8 |
   ```

## Requirements

- Python 3.6 or higher
- No external dependencies required

## Running the Game

```bash
python tic_tac_toe.py
```

The game will guide you through the setup and gameplay process. Enjoy!
