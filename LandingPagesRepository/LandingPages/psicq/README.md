# Psicóloga Andrea Cevallos - Website Profesional

Un sitio web moderno y profesional para la psicóloga Andrea Cevallos, diseñado para presentar sus servicios de terapia psicológica de manera elegante y accesible.

## 🌟 Características

- **Diseño Moderno y Profesional**: Interfaz limpia con gradientes elegantes y tipografía cuidadosamente seleccionada
- **Totalmente Responsivo**: Se adapta perfectamente a todos los dispositivos (móvil, tablet, desktop)
- **Navegación Intuitiva**: Menú de navegación fijo con efectos de scroll suaves
- **Formulario de Contacto Funcional**: Sistema de agendamiento de consultas con validación
- **Animaciones y Transiciones**: Efectos visuales sutiles que mejoran la experiencia del usuario
- **Optimizado para SEO**: Meta etiquetas y estructura semántica para mejor posicionamiento
- **Accesibilidad**: Soporte para navegación por teclado y lectores de pantalla

## 🔧 Personalización

### Colores
Modificar las variables CSS en `styles.css`:
```css
:root {
    --primary-color: #667eea;
    --secondary-color: #764ba2;
    --text-dark: #2c3e50;
    --text-light: #555;
    --background-light: #f8f9fa;
}
```

### Tipografía
Cambiar las fuentes en `index.html`:
```html
<link href="https://fonts.googleapis.com/css2?family=TuFuente:wght@300;400;500;600&display=swap" rel="stylesheet">
```

### Contenido
Editar directamente en `index.html` manteniendo la estructura semántica.
